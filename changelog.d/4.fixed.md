`date_diff` no longer raises `UnsupportedFeatureError` on a function BigQuery has had since 2016, and `supports_functions()` / `supports_json_function()` no longer return `None` — the latter made a test asking whether a function was supported raise `AttributeError` on the result rather than skip, and an empty mapping would have skipped tests BigQuery passes, so both now answer the core function set less the two BigQuery spells differently plus its JSON functions.
